<details>
<summary>💊 <b>Meditrack</b> — Acompanhamento de tratamentos médicos — <i>Next.js, React, TypeScript</i></summary>

<br>

Plataforma web que conecta **médicos e pacientes** no acompanhamento de tratamentos com medicamentos.

- 👨‍⚕️ **Área do médico:** cadastro de pacientes, criação de prescrições com medicamentos e horários, e painel com a **adesão ao tratamento** de cada paciente (alta/baixa adesão, doses perdidas).
- 🧑 **Área do paciente:** lista de medicamentos, doses do dia, registro de cada dose tomada e calendário do tratamento.
- 🔐 Autenticação separada para médico e paciente.

**Stack:** Next.js • React • TypeScript • Tailwind CSS • Radix UI • Recharts
